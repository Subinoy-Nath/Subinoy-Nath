    <td valign="top" style="border: none; padding-left: 20px;">
      <h3 style="margin-top: 0; margin-bottom: 8px; color: #ffffff;">Symbolic Regression</h3>
      <p style="margin-top: 0; line-height: 1.6; color: #cbd5e1;">
        Symbolic Regression is a machine learning method that searches mathematical spaces to find the equations that best model a given dataset. Unlike standard regression which optimizes weights for a fixed structure (like linear or polynomial curves), Symbolic Regression discovers both the <b>functional form</b> and the <b>parameters</b> simultaneously.
      </p>
      <p style="margin-top: 10px; line-height: 1.6; color: #cbd5e1;">
        By leveraging evolutionary search algorithms—specifically genetic programming—mathematical expressions are represented as tree structures that evolve over generations. This approach optimizes for both prediction accuracy and simplicity, resulting in mathematically interpretable, physically consistent equations that explain the data without relying on black-box neural networks.
      </p>
    </td>
